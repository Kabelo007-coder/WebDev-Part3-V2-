# Kays Clothing Co

A responsive e-commerce website for Kays Clothing Co, a local South African clothing brand specializing in quality jackets, apparel, and accessories.

Live Site: **[https://kaysclothingco.netlify.app/](https://kaysclothingco.netlify.app/)**

## Project Overview

This website was built as part of a web development portfolio to showcase modern front-end development skills, responsive design, and SEO best practices. The site features a clean, user-friendly interface designed to highlight the brand's products.

## Features

- **Responsive Design** - Fully optimized for mobile, tablet, and desktop
- **Image Gallery** - Product showcase with optimized images
- **SEO Optimized** - Includes `sitemap.xml` and `robots.txt` for search engine indexing
- **Clean UI** - Modern layout with Hero section and product categories
- **Contact Section** - Email integration for customer inquiries

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Netlify (Hosting & Deployment)
- GitHub (Version Control)

## SEO

- `sitemap.xml` - Includes all pages and 14 optimized images for Google indexing
- `robots.txt` - Configured to allow all crawlers and point to sitemap

## Deployment

This site is automatically deployed via Netlify from GitHub.

1. Connected GitHub repository to Netlify
2. Netlify builds on every push to main branch
3. Live URL: **[https://kaysclothingco.netlify.app/](https://kaysclothingco.netlify.app/)**
